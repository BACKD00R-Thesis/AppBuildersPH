# Development

Everything you need to run Brainrot Study locally and make changes. If a step here is wrong or missing, fix this doc in the same PR.

## Prerequisites

| Tool | Version | Why |
|---|---|---|
| Node.js | 20 LTS or newer | Expo app (SDK 57) |
| Python | 3.11 or 3.12 | FastAPI backend. Core works on newer versions, but the AI engines (PyTorch, CTranslate2) publish wheels for new Pythons late |
| Ollama | latest | Local LLM |
| FFmpeg | 6 or newer, built with `libass` and `libx264`, on `PATH` | Video rendering |
| Git | any recent | Source control |
| Expo Go app | latest | Running the app on your phone |

Optional: an NVIDIA GPU with CUDA speeds up faster-whisper and TTS. Everything works on CPU.

Hardware we test on: a laptop with 16 GB RAM. 8 GB works with `qwen2.5:3b` and the `base` Whisper model, but rendering is slower.

On Windows, `winget install Gyan.FFmpeg` and `winget install Ollama.Ollama` install the two binaries. Open a new terminal afterwards so `PATH` updates.

## First-time setup

```bash
git clone <your-fork-url>
cd <repo>
cp .env.example .env
```

Every variable has a working default, so you only need to fill in what differs on your machine (see [Environment variables](#environment-variables)). Blank values mean "use the default".

### 1. Backend

```bash
cd server
python -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt            # API + pipeline (light)
pip install -r requirements-engines.txt    # Kokoro, Piper, faster-whisper (heavy, downloads PyTorch)
python -m app.scripts.init_db
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Open `http://localhost:8000/health`. It reports whether Ollama, TTS, Whisper, and FFmpeg are ready. Interactive API docs are at `http://localhost:8000/docs`.

**No models yet?** Set `TTS_ENGINE=dummy` in `.env`. Voices become soft beeps (one per word) so you can build and test the whole flow, including rendering, before downloading anything. Without faster-whisper installed, captions use estimated word timing.

### 2. Models

```bash
ollama pull llama3.2:3b        # or: ollama pull qwen2.5:3b, then set OLLAMA_MODEL
python -m app.scripts.download_models   # from server/, pre-fetches TTS and Whisper weights for offline use
```

For Piper instead of Kokoro, download the two voice models named in [assets/characters/manifest.json](../assets/characters/manifest.json) (`en_US-ryan-medium`, `en_GB-alan-medium`, each an `.onnx` plus `.onnx.json`) into `models/piper/`, and set `TTS_ENGINE=piper`.

### 3. Mobile app

```bash
cd apps/mobile
npm install
npx expo start
```

Scan the QR code with Expo Go. Your phone and laptop must be on the same Wi-Fi or hotspot.

In the app, open **Server** (gear icon) and enter your laptop's LAN address, for example `http://192.168.1.23:8000`. Don't use `localhost`: on the phone, that means the phone itself. Find the address with `ipconfig` (Windows) or `ipconfig getifaddr en0` (macOS). The app remembers it.

To prefill the address, put `EXPO_PUBLIC_API_URL` (and `EXPO_PUBLIC_API_PAIRING_TOKEN`) in `apps/mobile/.env`. Expo only reads `.env` from the app folder, not the repo root.

**Web preview:** `npx expo start --web` runs the app in a browser, which is handy for UI work. Set `API_CORS_ORIGINS=http://localhost:8081` on the server so the browser may call it. Saving and sharing videos are phone-only.

### 4. Background clips and fonts

Two backgrounds are built in ("Game of Life" and "Plain dark"), generated by FFmpeg. To add gameplay clips, put MP4 files in `assets/backgrounds/` (ideally 1080x1920 or larger and at least 60 seconds long) and list each in `assets/backgrounds/manifest.json`:

```json
[{ "id": "parkour-01", "name": "Parkour", "file": "parkour-01.mp4", "duration_s": 300 }]
```

`duration_s` lets each render start at a random point in the clip. Clips are git-ignored: only use footage you recorded or are licensed to use.

Captions use **Montserrat ExtraBold**. Drop `Montserrat-ExtraBold.ttf` (free, SIL Open Font License) into `assets/fonts/`; without it FFmpeg falls back to a system font.

## Environment variables

[.env.example](../.env.example) lists every variable. Summary:

| Variable | Default | Purpose |
|---|---|---|
| `API_HOST`, `API_PORT` | `0.0.0.0`, `8000` | Where `python -m app` listens (plain `uvicorn` uses its own flags) |
| `API_PAIRING_TOKEN` | empty (off) | Shared secret; when set, every request must send it |
| `API_CORS_ORIGINS` | empty | Comma-separated origins for the web preview |
| `DATA_DIR` | `./data` | Uploaded PDFs, audio, captions, renders, and the database |
| `MODELS_DIR` | `./models` | Downloaded TTS and Whisper models |
| `DATABASE_URL` | `sqlite:///<DATA_DIR>/brainrot.db` | SQLite connection string |
| `OLLAMA_HOST`, `OLLAMA_MODEL`, `OLLAMA_TIMEOUT_S` | `http://localhost:11434`, `llama3.2:3b`, `180` | LLM endpoint and model |
| `TTS_ENGINE` | `kokoro` | `kokoro`, `piper`, or `dummy` |
| `KOKORO_VOICE_A/B`, `PIPER_VOICE_A/B` | from the character manifest | Override the asker (A) and explainer (B) voices |
| `WHISPER_MODEL`, `WHISPER_DEVICE`, `WHISPER_COMPUTE_TYPE` | `small`, `cpu`, `int8` | Alignment model and hardware |
| `FFMPEG_PATH` | `ffmpeg` | FFmpeg binary |
| `RENDER_WIDTH`, `RENDER_HEIGHT`, `RENDER_FPS` | `1080`, `1920`, `30` | Output video format |
| `EXPO_PUBLIC_API_URL` | empty | App: prefilled server address (in `apps/mobile/.env`) |
| `EXPO_PUBLIC_API_PAIRING_TOKEN` | empty | App: prefilled pairing token |

Never commit `.env`. Add new variables to `.env.example`, `server/app/config.py`, and this table in the same PR.

## Database

- SQLite at `DATABASE_URL`. Tables: `project`, `line`, `render` ([server/app/models.py](../server/app/models.py)).
- `python -m app.scripts.init_db` creates missing tables (the server also does this on startup); `--reset` drops all data.
- There are no migrations yet. Until we add Alembic, a schema change means `init_db --reset` locally; note it in your PR.
- Deleting `DATA_DIR` resets everything, including renders.

## Common commands

| Task | Command (run from) |
|---|---|
| Start backend with reload | `uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload` (`server/`) |
| Start backend from `.env` settings | `python -m app` (`server/`) |
| Backend tests | `pytest` (`server/`); the render test is skipped if FFmpeg isn't on `PATH` |
| Backend lint and format | `ruff check . && ruff format .` (`server/`) |
| Start the app | `npx expo start` (`apps/mobile/`) |
| App lint | `npm run lint` (`apps/mobile/`) |
| App type check | `npm run typecheck` (`apps/mobile/`) |
| App dependency check | `npx expo-doctor` (`apps/mobile/`) |
| Add an app dependency | `npx expo install <package>` (never plain `npm install`: it picks SDK-compatible versions) |
| Print a script for a PDF | `python -m app.scripts.script_sample file.pdf --pages 1-5` (`server/`) |
| Render a video from the CLI | `python -m app.scripts.render_sample file.pdf` or `--script lines.txt` to skip the LLM (`server/`) |
| Redraw placeholder characters | `python -m app.scripts.make_placeholder_characters` (`server/`) |

## Common workflows

### Change the dialogue prompt

1. Edit [server/app/pipeline/prompts/dialogue.txt](../server/app/pipeline/prompts/dialogue.txt). Placeholders use `$name` syntax.
2. Run `python -m app.scripts.script_sample path/to/file.pdf` to print the generated script without rendering.
3. Check it against two or three different PDFs before opening a PR.

### Add or change a character

1. Add a transparent PNG (around 512x512) to `assets/characters/`.
2. Add an entry to `assets/characters/manifest.json`: `id`, `name`, `role` (`asker` or `explainer`), `persona` (goes into the prompt), `color`, `voices` (per engine), and `image`.
3. Restart the backend; the character appears in `GET /assets/characters`. The MVP uses exactly one asker and one explainer.

### Debug a failed render

1. The app shows the error; `GET /renders/{id}` has the failed step and message.
2. Intermediate files are in `DATA_DIR/projects/{project_id}/`: per-line WAVs and word timings in `audio/`, and `captions.ass`, `voice.wav`, and `render.log` (every FFmpeg command and its output) in `renders/{render_id}/`.
3. Re-run the logged FFmpeg command from that folder to see the full output.

## Troubleshooting

- **App can't reach the backend:** check the address uses the LAN IP, the backend was started with `--host 0.0.0.0`, and your OS firewall allows port 8000 for private networks.
- **Script generation fails:** run `ollama list` to confirm the model is pulled and that Ollama is running. `/health` shows the exact problem.
- **"Kokoro isn't installed":** run `pip install -r requirements-engines.txt`, or set `TTS_ENGINE=dummy` while developing.
- **FFmpeg not found:** set `FFMPEG_PATH` to the full path of the binary.
- **Out of memory during render:** switch to `qwen2.5:3b`, use `WHISPER_MODEL=base`, and close other apps.
- **Development build can't load http:// URLs:** cleartext HTTP to the LAN is enabled through `expo-build-properties` in `app.json`; rebuild the dev client after changing it. Expo Go allows it already.
